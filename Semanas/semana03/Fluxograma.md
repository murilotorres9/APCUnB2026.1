# Fluxograma de algoritmo no LMC

## Descrição
Este repositório contém um fluxograma desenvolvido para representar a lógica de um algoritmo implementado em Little Man Computer (LMC).

## Estrutura do Fluxograma
1. Início do programa;
2. Entrada dos dados;
3. Processamento das informações;
4. Verificação de condições;
5. Exibição do resultado;
6. Encerramento do programa.
