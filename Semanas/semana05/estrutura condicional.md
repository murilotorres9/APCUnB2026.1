### 7. OctoStudio

Desenvolvimento de um projeto chamado:

** Semáforo Inteligente**

Funcionalidades:

- Botão alterna os estados do semáforo
- Uso de estruturas condicionais
- Compartilhamento do projeto pelo WhatsApp

  **Descrição do algoritmo:**
Um sprite representa a luz do semáforo. Uma variável `estado` guarda o valor
atual (`"vermelho"`, `"amarelo"` ou `"verde"`). Ao tocar no botão, um bloco
`se estado = "vermelho" então estado <- "verde"` (e assim por diante) alterna
o estado e muda a cor/imagem do sprite.

**Pseudocódigo:**
```
se estado == "vermelho"
    estado <- "verde"
senão se estado == "verde"
    estado <- "amarelo"
senão
    estado <- "vermelho"
mostrar cor correspondente a estado
```
