# Relatório — Code.org, módulo "Loops e Otimização" (Semana 6)

- **Conclusão dos desafios propostos:** Concluí todos os desafios do módulo **"Loops e Otimização"**. As atividades envolveram o uso de estruturas de repetição para controlar os movimentos dos personagens e resolver problemas utilizando menos blocos de código.

- **Explicação do algoritmo em linguagem natural:** Em um dos desafios, o personagem precisava repetir a mesma sequência de movimentos várias vezes para chegar ao objetivo. Em vez de repetir os comandos manualmente, foi utilizado um laço de repetição que executava automaticamente a sequência até completar o percurso, deixando o algoritmo mais simples e organizado.

- **Erros identificados e correções:** Durante um dos desafios, defini uma quantidade incorreta de repetições no laço, fazendo com que o personagem não chegasse ao destino esperado. Após revisar a lógica do algoritmo, corrigi o número de repetições e o desafio foi concluído com sucesso.

- **Reflexão sobre a própria aprendizagem:** Depois de realizar as atividades, ficou mais claro como os laços de repetição ajudam a reduzir código repetitivo e tornam os programas mais eficientes. Também compreendi melhor a diferença entre repetir comandos manualmente e utilizar estruturas como `for` e `while` para automatizar tarefas.
