# Roteiro — Apresentação do projeto final (10 min + 5 de perguntas)

## Estrutura sugerida

**1. Abertura (1 min)**
- Nome do recurso educacional e qual problema pedagógico ele resolve

**2. Demonstração ao vivo (4–5 min)**
- Rodar o código na frente da turma (`python3 src/main.py` ou equivalente)
- Mostrar uma entrada real e o resultado
- Se houver simulador OctoStudio/Tinkercad associado, mostrar também

**3. Decisões técnicas (2 min)**
- Quais estruturas de dados/algoritmos das semanas anteriores foram
  reaproveitados (ex.: busca binária da semana 11, recursão da semana 14)
- Um desafio de depuração que apareceu durante o desenvolvimento

**4. Proposta pedagógica (2 min)**
- Faixa etária, competência da BNCC-Computação, como usar em uma aula real

**5. Reflexão sobre o semestre (1 min)**
- O que mudou desde o primeiro programa no OctoStudio (semana 1) até aqui

**6. Perguntas (5 min)**
- Repositório aberto na tela para responder dúvidas olhando o código

## Checklist antes de apresentar
- [ ] Código roda sem erro do zero (`git clone` limpo + rodar)
- [ ] README do projeto final está completo
- [ ] Proposta pedagógica preenchida
- [ ] Repositório aberto no navegador, pronto para mostrar
