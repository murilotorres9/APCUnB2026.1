# Configurar GitHub Pages (Semana 15)

## Passo a passo

1. No repositório `murilotorres9/APCUnB2026.1`, vá em **Settings**.
2. No menu lateral, clique em **Pages**.
3. Em **Build and deployment → Source**, selecione **Deploy from a branch**.
4. Em **Branch**, selecione `main` e a pasta `/ (root)` (já que o
   `index.html` está na raiz do repositório).
5. Clique em **Save**.
6. Aguarde 1–2 minutos. A URL publicada aparece no topo da página de
   Settings → Pages, no formato:
   ```
   https://murilotorres9.github.io/APCUnB2026.1/
   ```
7. Registre essa URL no formulário da turma (pedido pelo professor).
