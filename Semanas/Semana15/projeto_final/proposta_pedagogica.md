# Proposta pedagógica

**Sugestão de recurso (baseado no trabalho do semestre):** um "Analisador de
desempenho escolar" simplificado para uso em sala de aula, reaproveitando
`banco_dados.py` (semana 11), `agenda_contatos.py` (semana 12) e
`analisador_saeb.py` (semana 14), com uma interface de linha de comando
simples que um(a) professor(a) de Ensino Fundamental poderia usar para
mostrar aos alunos, de forma concreta, como dados viram informação.

**Atividade de sala de aula (45 min):**
1. (10 min) Alunos preenchem um CSV coletivo com notas fictícias da turma.
2. (15 min) Rodam o script e discutem o que significa "ordenar" e "buscar".
3. (15 min) Em duplas, alteram um critério de filtragem (ex.: por matéria) e
   observam o efeito no resultado.
4. (5 min) Fechamento: relacionar com o conceito de algoritmo trabalhado
   desde a semana 1 (semáforo, contador) até este projeto.

**Competências da BNCC-Computação:** pensamento computacional (decomposição,
abstração, algoritmos), cultura digital (uso ético de dados escolares).
